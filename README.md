## Tech Stack

| Technology   | Description                                          |
| ------------ | ---------------------------------------------------- |
| C#           | Programming language used for backend development    |
| .NET         | Framework for building and running C# applications   |
| ASP.NET Core | Web framework for building web applications and APIs |
